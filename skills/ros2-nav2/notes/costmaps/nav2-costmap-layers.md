# Costmap layers: static, inflation, plugin order

**TL;DR** Each costmap is the superposition of layers, applied in the order of its `plugins` list. Put sensor layers (obstacle/voxel) **before** `inflation_layer`, or new obstacles are not inflated.

## Available layers
| Layer (plugin) | Adds to the costmap |
|---|---|
| Static (`nav2_costmap_2d::StaticLayer`) | every black (occupied) cell of the static map, e.g. one made by SLAM |
| Inflation (`nav2_costmap_2d::InflationLayer`) | an inflation around any obstacle: a safe distance to keep |
| Obstacle (`nav2_costmap_2d::ObstacleLayer`) | objects detected by a 2D sensor (laser) ([[nav2-costmap-obstacle-voxel]]) |
| Voxel (`nav2_costmap_2d::VoxelLayer`) | 3D obstacles from point clouds, projected to 2D ([[nav2-costmap-obstacle-voxel]]) |

Use one or all of them: add each name to `plugins` and give its parameters under that name.
```yaml
      plugins: ["static_layer", "obstacle_layer", "inflation_layer"]
```

## Static layer (Humble defaults)
```yaml
      static_layer:
        plugin: "nav2_costmap_2d::StaticLayer"
        map_subscribe_transient_local: True
```
The static layer represents the largely unchanging part of the costmap, like a map generated by SLAM.
| Parameter | Default | Meaning |
|---|---|---|
| `enabled` | true | whether it is enabled |
| `map_subscribe_transient_local` | true | QoS for the map topic (latched map) |
| `subscribe_to_updates` | **false** | also subscribe to map updates after the first map |
| `transform_tolerance` | **0.0** s | TF tolerance |
| `map_topic` | `""` (uses the costmap's `map_topic`, default `map`) | map topic for this layer |

## Inflation layer (Humble defaults)
```yaml
      inflation_layer:
        plugin: "nav2_costmap_2d::InflationLayer"
        cost_scaling_factor: 3.0
        inflation_radius: 0.35
```
The inflation layer adds costs around lethal obstacles (inflates them) so the costmap represents the robot's configuration space.
| Parameter | Default | Meaning |
|---|---|---|
| `enabled` | true | whether it is enabled |
| `inflation_radius` | 0.55 m | radius to inflate the costmap around lethal obstacles |
| `cost_scaling_factor` | **10.0** | exponential decay factor across the inflation radius (higher = cost drops faster) |
| `inflate_unknown`, `inflate_around_unknown` | false | also inflate unknown cells / around them |

## Pitfalls
- `inflation_radius` smaller than the robot radius → paths hug walls ([[core-nav2-tuning]]).
- A layer listed in `plugins` without its `plugin:` type (or vice versa) → load error or the layer is ignored.
- Wrong indentation: a layer block must be at the same level as `static_layer`.
